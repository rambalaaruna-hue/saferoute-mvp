# 🚀 SafeRoute - Quick Start

## ⚡ Start in 30 Seconds

```bash
npm install
npm run dev
```

Open: **http://localhost:5173**

**Done! App works in Demo Mode!**

## 🎯 Try It Out

1. **Enter locations:**
   - Start: `Times Square, New York, NY`
   - Destination: `Central Park, New York, NY`

2. **Click:** "Find Safe Routes"

3. **See:** 3 routes with safety scores

4. **Select:** Any route to see details

5. **Navigate:** Click "Start Navigation" for turn-by-turn
