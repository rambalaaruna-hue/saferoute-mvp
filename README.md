# SafeRoute 🛡️

**AI-powered navigation for safer travel at night**

## 🌐 Live Demo
https://saferoute-three.vercel.app

## ✨ Features
- **Smart Route Analysis** - AI evaluates routes based on lighting, crowd density, and safety factors
- **Safety Scores** - Each route rated 0-100 with color-coded visualization
- **Real-time Navigation** - Google Maps integration with turn-by-turn directions
- **SOS Emergency** - Quick access to emergency contacts and services
- **AI Safety Insights** - Gemini AI explains why routes are safer

## 🛠️ Tech Stack
- React + TypeScript + Vite
- Google Maps API (Directions, Places, Geocoding)
- Google Gemini AI
- Firebase Authentication
- Tailwind CSS

## 🚀 Quick Start
```bash
npm install
npm run dev
```
