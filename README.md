# SafeRoute – AI-powered Night Travel Safety

## Problem
Women often feel unsafe while traveling at night due to poorly lit roads,
isolated areas, and lack of real-time safety insights.

## Solution
SafeRoute helps users check how safe a route is before traveling at night.
It provides a safety level and AI-generated explanation based on crowd presence,
lighting, and reported incidents. Users can also report unsafe areas to help others.

## Features
- Route safety scoring (Low / Moderate / High)
- AI-based safety explanation (mocked)
- Incident reporting (mock)
- Clean, mobile-friendly UI

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend (Mock): Node.js, Express
- Google Technologies (Planned):
  - Google Maps API
  - Gemini API
  - Firebase
